# 練習 01：HTML 基礎語法（手動完成・免用 AI）

歡迎來到第一個實作練習！這一題**不需要使用 AI**，請直接用你剛學到的 HTML 標籤觀念手動完成。

## 操作步驟

1. 先到資料夾裡雙擊打開 `index.html`，用瀏覽器看看現在壞掉的畫面（你會發現所有字都變得超大，而且少了自我介紹與按鈕）。
2. 在 Cursor 點選 `File -> Open Folder...` 打開這個 `exercise-01-basic-html` 資料夾。
3. 點開左側的 `index.html`，依照裡面的 **4 個中文註解任務（任務 1 ～ 任務 4）** 修改 HTML。
4. 每改完一項，按 `Cmd + S`（Windows 按 `Ctrl + S`）存檔，回到瀏覽器重新整理看看變化！
