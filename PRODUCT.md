# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vite-bundled presentation web application configured for static GitHub Pages deployment (`base: './'` / GitHub Actions Pages workflow).

## Users

- **Primary (Instructor):** Secondary school teacher or workshop facilitator projecting slides in a classroom across four 45–60 minute lessons, pacing live demos and hands-on checkpoints.
- **Secondary (Students):** Zero-programming-background secondary school students opening the deployed GitHub Pages URL on classroom computers or personal devices to follow lesson steps, copy ready-made Cursor prompts, and review concepts after class.

## Product Purpose

Deliver a complete 4-lesson introductory Vibe Coding curriculum and dual-purpose classroom presentation website that guides secondary school students with zero coding experience from opening Cursor for the first time to building and iterating a lightweight interactive web project (e.g., an interactive mini-game or micro-tool) with HTML, CSS, and JavaScript.

## Positioning

Designed specifically for 45–60 minute secondary school periods without syntax memorization: instead of teaching boilerplate HTML/CSS/JS by rote, students learn the Vibe Coding loop—Describe clearly, Preview immediately, Inspect & Fix with Cursor AI—supported by live-projectable slides and one-click copyable classroom prompts.

## Operating Context

- **Schedule:** 4 lessons × 45–60 minutes each, structured around one lightweight single-project arc so students finish with a working, playable/usable web artifact without requiring every student to configure GitHub accounts if classroom time is constrained (deployment is demonstrated and offered as an optional/extension step).
- **Tools Taught:** Cursor (Chat / Agent mode, Tab / Inline Edit), browser live preview & DevTools inspection, and conceptual roles of HTML (structure), CSS (style), and JavaScript (interactivity).
- **Classroom & Review Usage:** Keyboard-driven slide navigation (arrow keys, spacebar, slide overview/jump by lesson) for live teaching, paired with copyable prompt blocks and clear step markers for students following along.
- **Language:** Traditional Chinese (繁體中文) instructional text paired with authentic English Cursor UI terms and web terminology.

## Capabilities and Constraints

- Static build output deployable directly to GitHub Pages without server-side dependencies.
- Structured 4-lesson curriculum progression with lesson objectives, time pacing, live demo checkpoints, copyable Cursor prompts, common troubleshooting tips, and wrap-up checklists.
- No fabricated student testimonials, school partnerships, or completion statistics.
- Must remain legible both when projected on a classroom screen (16:9 desktop/projector) and when opened by students on narrower laptop or mobile viewports.

## Evidence on Hand

- Greenfield curriculum and presentation build; lesson outlines, time breakdowns, hands-on activities, and Cursor prompt templates are authored directly for this 4-lesson secondary school course.
- No external images, logos, or institutional brand assets supplied.

## Product Principles

1. **Zero-Jargon Entry, Real Tools:** Use Cursor and real HTML/CSS/JS files from Lesson 1 without expecting students to memorize syntax before seeing results.
2. **One Lightweight Arc:** Keep all 4 lessons anchored to building and refining one tangible, fun web project appropriate for 45–60 minute periods.
3. **Projector-Ready & Student-Friendly:** Every slide works at presentation distance while remaining practical for students to read and copy prompts from directly.
4. **Prompt as Craft:** Teach students that specific instructions, constraints, and visual/behavioral feedback produce dramatically better AI output than vague one-liners.

## Accessibility & Inclusion

- High readability at classroom projection distance and standard WCAG AA contrast on interactive controls.
- Full keyboard navigation for presentation flow (`ArrowLeft`, `ArrowRight`, overview/lesson jump) and `prefers-reduced-motion` support.
