# 練習 04：失控的接星星小遊戲（請使用 Cursor AI 修復）

歡迎來到魔王關卡！這款《接星星大作戰：故障危機版》雖然能打開來玩，但裡面的物理與計分規則完全失控了！

請先雙擊打開 `index.html` 玩個 20 秒，找出所有詭異的地方，再用 **Cursor Agent / Chat (`Cmd + L` / `Ctrl + L`)** 一項一項指揮 AI 修好它！

## 試玩時你會發現的 4 個詭異 Bug

1. **左右方向鍵完全相反＋穿牆失蹤**：按左方向鍵 `←` 白色平台居然往右跑，按右方向鍵 `→` 反而往左跑；而且一直按著不放，平台會直接衝出畫面邊界再也回不來！
2. **獎懲完全顛倒**：辛苦接到黃色星星竟然**扣 10 分**，去撞紅色炸彈反而**加 50 分**！
3. **重玩變兩倍速暴走**：只要多按幾次「重新開始」，星星掉落的速度和倒數計時就會變成 2 倍、3 倍、4 倍快，瞬間失控！
4. **時間歸零不會停**：上方秒數倒數超過 `0` 之後竟然變成 `-1s`、`-2s`、`-3s` 繼續無限掉下去，永遠不會結算！

## 挑戰目標

- 用清楚的中文指令請 Cursor 修正以上 4 個問題（記得：如果 AI 不小心改壞畫面，隨時按對話框的 `Restore Checkpoint` 回溯）。
- 全部修好後，你還可以順便請 Cursor 幫你加上一個新功能（例如金色大星星 +30 分，或滑鼠拖曳控制）！
