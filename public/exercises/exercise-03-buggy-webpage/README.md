# 練習 03：怪異故障網頁除錯（請使用 Cursor AI 修復）

這是一個「班級電玩社報名計數與抽籤網頁」，看起來畫面很正常，但一實際點按就會出現 **4 個超詭異的故障行為**！

這一題**請不要自己硬啃程式碼**，練習當「除錯偵探」：先在瀏覽器親手試出所有怪現象、打開 `F12 Console` 找線索，再用 `Cmd + L`（Windows 按 `Ctrl + L`）清楚描述給 Cursor AI 幫你修好！

## 如何重現 4 個詭異現象？

1. **人數加法變天文數字**：目前報名人數是 `1`，連續點幾下「報名人數 +1」，數字竟然變成 `11` → `111` → `1111`，而不是 `2, 3, 4`！
2. **重設按鈕完全失靈**：想把壞掉的數字歸零，點擊「人數歸零」卻毫無反應！（提示：打開瀏覽器 `F12 -> Console` 看看有沒有紅色錯誤訊息）
3. **夜間模式變隱形墨水**：點擊右上角「切換深色模式」，背景變黑的瞬間，所有文字也跟著變成深黑色，整張卡片直接消失看不見！
4. **抽籤抽到幽靈 `undefined`**：點擊幾次「抽出今日值日生」，有時候竟然會顯示 `中獎同學：undefined`！

## 建議的 Vibe Coding 除錯步驟

- 在 Cursor 點選 `File -> Open Folder...` 打開 `exercise-03-buggy-webpage`。
- 一次告訴 AI 一個或多個你觀察到的「操作動作 → 實際怪現象 → 你期望的正常結果」，並請它解釋為什麼會發生這個 Bug！
