# 練習 02：CSS 視覺排版改造（手動完成・免用 AI）

這是一張《星際防衛戰》遊戲海報網頁，HTML 結構已經全部寫好了，但 CSS 數值設錯，導致**黑底黑字幾乎看不見、文字全部擠在邊框上、標題比內文還小**！

這一題同樣**不需要使用 AI**，請自己動手改 4 行 CSS 救回這張海報。

## 操作步驟

1. 雙擊打開 `index.html`，先在瀏覽器觀察目前慘不忍睹的排版。
2. 在 Cursor 點選 `File -> Open Folder...` 打開 `exercise-02-css-styling` 資料夾。
3. 這次**不用改 `index.html`**，請點開 `style.css`，找到 **任務 1 ～ 任務 4** 的註解位置修改數值。
4. 存檔（`Cmd + S` / `Ctrl + S`）並重新整理瀏覽器檢查成果！

## 完成檢查清單

- [ ] 任務 1：把 `.poster` 的文字顏色 `color` 改成 `#ffffff`（白色），讓深色海報上的字清楚浮現
- [ ] 任務 2：把 `.poster` 的內距 `padding` 從 `0px` 改成 `32px`，留出呼吸空間
- [ ] 任務 3：把大標題 `h1` 的字體大小 `font-size` 從 `12px` 放大成 `36px`
- [ ] 任務 4：把 `.start-btn` 按鈕背景 `background-color` 改成 `#d92b2b`、文字 `color` 改成 `#ffffff`、內距 `padding` 改成 `12px 24px`
